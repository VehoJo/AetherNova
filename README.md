# AetherNova

AetherNova is a futuristic Android UI project built with Jetpack Compose.

The project focuses on creating a clean, immersive interface with neon accents, soft glow effects, custom typography, gradients, and a space-inspired visual language.

## ✨ Features

- Modern futuristic UI
- Jetpack Compose based interface
- Custom typography using Orbitron and Plus Jakarta Sans
- Neon purple and yellow color palette
- Gradient backgrounds and buttons
- Custom glow and shadow effects
- Countdown components
- Milestone cards with customizable icons and content
- Responsive Compose layout
- Minimal and clean visual hierarchy

## 🎨 Design

AetherNova uses a dark interface with bright purple and yellow accents.

The design combines:
- futuristic typography
- soft neon glow
- rounded cards
- transparent surfaces
- subtle gradients
- large spacing and clean composition

The goal is to make the interface feel like a futuristic protocol / control interface rather than a traditional Android application.

## 📱 Current Status

AetherNova is currently a UI-focused project.

The main goal at this stage is to recreate and refine the interface in Android using Jetpack Compose.

Functionality and additional screens may be added later.

## 📂 Project Structure

The project follows a standard Android project structure with Compose UI components and a separate theme configuration.

Custom colors and fonts are stored in the project's theme package and reused across the interface.

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/VehoJo/AetherNova.git
```
Open the project in Android Studio and run it on an Android device or emulator.
